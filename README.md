# DuyBarberShop
Website quản lý và đặt lịch cắt tóc trực tuyến - ASP.NET Core MVC, C#, SQL Server


## 1. Giới thiệu đề tài

Hệ thống giúp khách hàng đặt lịch cắt tóc trực tuyến, nhân viên theo dõi lịch làm việc và quản trị viên quản lý hoạt động của tiệm.

## 2. Công nghệ dự kiến

- ASP.NET Core MVC
- C#
- SQL Server
- Entity Framework Core
- HTML, CSS, JavaScript
- Bootstrap 5

## 3. Các nhóm người dùng

### Khách hàng
- Đăng ký, đăng nhập
- Cập nhật thông tin cá nhân
- Xem, tìm kiếm, lọc dịch vụ
- Xem chi tiết dịch vụ
- Đặt lịch cắt tóc
- Xem lịch sử và hủy lịch hợp lệ

### Nhân viên
- Xem lịch được phân công
- Theo dõi công việc
- Cập nhật trạng thái thực hiện dịch vụ

### Quản trị viên
- Quản lý tài khoản
- Quản lý dịch vụ
- Quản lý nhân viên
- Quản lý lịch đặt và trạng thái
- Xem Dashboard và thống kê cơ bản

## 4. Lộ trình thực hiện

- Tuần 1: Khảo sát bài toán và xác định yêu cầu
- Tuần 2: Phân tích và thiết kế hệ thống
- Tuần 3: Xây dựng nền tảng hệ thống
- Tuần 4: Xây dựng chức năng quản lý dữ liệu
- Tuần 5: Xây dựng nghiệp vụ đặt lịch
- Tuần 6: Hoàn thiện nghiệp vụ và thống kê
- Tuần 7: Kiểm thử và triển khai
- Tuần 8: Hoàn thiện và bàn giao
